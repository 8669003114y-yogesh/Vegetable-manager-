VegBiz - भाजीपाला व्यवसाय - आवृत्ती 1

कसे वापरायचे:
1. ही साईट GitHub Pages वर चालू करा (खाली स्टेप्स). मग मिळालेली लिंक Chrome मध्ये उघडा.
2. Chrome मध्ये ⋮ → "Install app" किंवा "Add to Home screen". होम स्क्रीनवर ॲपसारखा आयकॉन येईल.
3. एकदा उघडल्यावर इंटरनेट गेलं तरी ॲप चालतं (जुना सेव्ह केलेला डेटा दिसतो). फक्त बाजारभाव आणि बातम्या आणायला इंटरनेट लागतं.

GitHub Pages चालू करायचे कसे:
- GitHub मध्ये नवीन Repository बनवा (उदा. नाव: vegbiz), Public ठेवा.
- "Add file" -> "Upload files" -> या फोल्डरमधल्या सगळ्या फाईल्स (index.html, manifest.json, sw.js, icon-192.png, icon-512.png, README.txt) एकत्र निवडा -> Commit.
- Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, Folder: / (root) -> Save.
- 1-2 मिनिटांनी लिंक मिळेल: https://तुमचा-username.github.io/vegbiz/

आधीचा डेटा नव्या लिंकवर आणायचा कसा:
- नवी लिंक वेगळी असल्यामुळे जुन्या फाईलचा डेटा आपोआप येत नाही.
- जुन्या फाईलमध्ये Home वर "डेटा सेव्ह करा + WhatsApp वर पाठवा" दाबा, फाईल स्वतःला पाठवा.
- नव्या लिंकवर Home वर "जुना डेटा परत घ्या (Restore)" दाबून ती फाईल निवडा.
- मग रोज अधूनमधून तोच बॅकअप पाठवत राहा. डेटा फक्त त्या फोनच्या Chrome मध्ये साठतो.

अपडेट करायचं असेल तेव्हा:
- index.html बदला आणि sw.js मधलं CACHE चं नाव बदला (vegbiz-v1 -> vegbiz-v2). मग सगळ्यांच्या फोनवर नवीन आवृत्ती येते.
